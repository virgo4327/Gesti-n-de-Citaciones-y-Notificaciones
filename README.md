# Gestión de Citaciones y Notificaciones — DEPDICC Iquitos

Aplicación web institucional para crear citaciones, notificaciones policiales, vista previa documental y PDFs oficiales.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build producción

```bash
npm run build
```

## Despliegue

Push a `main` → Vercel despliega automáticamente.

## Variables de entorno

Copiar `.env.example` a `.env.local`.
